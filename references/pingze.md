# 简化平仄（现代普通话）——与近体诗传统规则明确区分

## 本项目现代简化规则（v1 唯一实现）

以现代标准普通话声调为基准：

| 普通话声调 | 例 | 简化平仄 |
|---|---|---|
| 第一声（阴平） | 天 tiān、窗 chuāng | **平** |
| 第二声（阳平） | 长 cháng、城 chéng | **平** |
| 第三声（上声） | 纸 zhǐ、晓 xiǎo | **仄** |
| 第四声（去声） | 路 lù、向 xiàng | **仄** |
| 轻声 | 的 de、了 le | **轻**（不参与韵部；**不强制归入平或仄**——位于 2/4/6 关键位或韵脚时按 RELATION=UNCERTAIN 处理并给出 WARN，需人工确认或用 --reading 指定实读） |

> ⚠️ **这是本项目创作系统的简化约定，不是历史近体诗学的完整规则。**
> 传统近体诗学以中古音（《切韵》系）为基准，存在**入声韵/入声字**体系（如 雪、月、客、国 在传统规则中多为入声=仄），现代普通话已无入声。涉及古体诗鉴定、古人作品分析时**不得**套用本简化规则。

## 多音字策略（确定性、可审计）

- 单字默认取数据表**首位读音**；该顺序 = 底层字典返回顺序（DEFAULT_SOURCE = dictionary_order），**不等于严格词频/通用度排序**。多音字必须暴露全部候选读音，并允许人工/上下文用 `--reading` 覆盖。
- 示例：长 默认 zhǎng(仄)；诗中"路长/天长"语义下必须用 `--reading 长=chang2` 锁定为平。
- 客舍的舍 默认 shě(三声，动词)；名词"客舍/旅舍"读 shè(四声)，可用 `--reading 舍=she4`。两者均为仄，通常不影响判断，但读音标注必须准确。
- 斜 默认 xié(二声，平)；**不采用**古读 xiá——本项目以现代普通话发音为准（references/sources.md 有说明）。
- 一 默认 yī(一声，平)；口语连读变调（yí/yì）**不**作为诗词平仄依据（本项目简化规则按字典本调）。
- 看 默认 kàn(四声)；"看守"义 kān(一声) 需手动指定。

## 与近体传统规则的差异速查

| 项目 | 传统近体（中古音） | 本项目（现代简化） |
|---|---|---|
| 平仄依据 | 平上去入四声（含入声） | 普通话 1/2=平，3/4=仄 |
| 入声字 | 独立仄声类（月、客、国、别…） | 已归入普通话各声调，按实际声调 |
| 多音/异读 | 按韵书与语义 | 默认取底层字典第一候选（DEFAULT_SOURCE=dictionary_order，非词频排序），语义明确时 --reading（含位置级）指定 |
| 轻声 | 不适用 | 单独标记"轻" |
| 用途 | 古典作品分析 | 本项目现代白话格律创作 |
