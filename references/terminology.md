# 术语表

| 术语 | 含义（本项目语境） |
|---|---|
| 绝句（jueju） | 四句体近体诗。五言=五绝（4×5字）、七言=七绝（4×7字） |
| 联 | 两句为一联：1-2 首联、3-4 尾联（绝句仅两联） |
| 出句 / 对句 | 每联上句为出句，下句为对句 |
| 平 / 仄 | 本项目=现代简化：普通话 1/2 声为平、3/4 声为仄（见 pingze.md） |
| 韵脚 | 句尾押韵字；绝句中第2、4句句尾为必查韵脚 |
| 入韵 / 不入韵 | 指首句句尾是否参与押韵（平收同部=入韵） |
| 相对（对） | 联内两句关键位（2、4〔、6〕字）平仄相反 |
| 相粘（粘） | 第2句与第3句关键位平仄同类（联间声音连续） |
| 失对 / 失粘 | 关键位未相反 / 未同类（确定性规则事实） |
| 韵部（韵书） | 按韵书分部的押韵类别。本项目支持：中华新韵十八韵、中华新韵十四韵、十三辙 |
| 辙口 | 十三辙的韵部（曲艺/歌词听感分类），一七、姑苏、江阳、中东等 |
| PERFECT_RHYME | 押韵级别：明确押韵（同部/同辙） |
| NEAR_RHYME | 押韵级别：近韵（听感启发式组内），宽松创作可用但需提醒 |
| NO_RHYME | 押韵级别：明显不押韵 |
| UNCERTAIN | 押韵/平仄级别：无法可靠判断（轻声、无数据），**禁止猜测** |
| 轻声 | 普通话弱读音节（的 de、了 le）；单独标记"轻"，不参与韵部 |
| i_apical | 舌尖元音 -i（zh/ch/sh/r/z/c/s 后的 i），韵书归类与普通 i（齐韵）不同 |
| 多音字（异读） | 一字多音。数据表默认取底层字典返回的第一读音（DEFAULT_SOURCE=dictionary_order，非词频排序）；必须暴露候选并允许 --reading（含位置级 行:列=拼音）锁定 |
| --reading | check_poem/check_rhyme 参数：`字=拼音`（如 长=chang2）指定某字读法 |
| 入声 | 中古四声之一（现代普通话已消失，多归入各调）。**本项目现代简化规则不含入声体系** |
| 古绝 | 不受近体粘对/平仄模板约束的绝句（允许失粘失对） |
